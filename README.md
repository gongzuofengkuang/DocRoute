# DocRoute 檔案整理工具

**DocRoute** — Offline OCR naming & document routing toolkit
掃描檔辨識命名、依規則決定歸檔位置、整理共用資料夾素材，全部在一個網頁完成；不需安裝、不需網路、不上傳任何檔案。

---

## 1. 這個工具做什麼

| 分頁 | 用途 |
|---|---|
| **素材索引** | 匯入資料夾的檔案清單（CSV），依「分類規則」整理成目錄；可搜尋、篩選修改日期與標別，勾選後產生複製程式碼。「歸檔建議」會依「目的資料夾規則」標出每個檔案建議放的位置，勾選後可「送到建議位置」。常用的資料夾（含子資料夾）、細項或標別可按 ☆ 訂閱，再按「★ 只看訂閱」縮小檢索範圍。 |
| **文字辨識命名** | 選資料夾或拖入掃描 PDF／JPG／PNG，辨識前 3 頁文字，依「命名規則」建議檔名，依「目的資料夾規則」算出存放位置；人工訂正確認後，產生送件（複製改名）的 PowerShell 程式碼。 |
| **分類規則** | 素材索引的大類與細項（關鍵字比對）。 |
| **命名規則** | 文件類別判定與檔名範本（規則.xlsx）。 |
| **目的資料夾規則** | 案別、事件、次別與分送規則（自動歸檔規則.xlsx）；素材索引與文字辨識命名共用。附「試算」：輸入檔名立即看到判定結果。 |
| **說明** | 操作說明。 |

## 2. 檔案

```
index.html       ← 整個工具（約 13.6 MB，已內含辨識引擎與中英文語言檔）
README.md        ← 本說明
AI協作說明.md    ← 給 AI 的前置說明（網頁「說明」分頁也可下載，並自動附上目前規則摘要）
```

## 3. 系統需求

- **瀏覽器**：新版 Chrome 或 Edge（需支援「資料夾授權」功能；Firefox、Safari 不支援選資料夾）。
- **作業系統**：辨識命名與索引任何系統皆可；「送件」產生的 PowerShell 程式碼需在 Windows 執行（Windows PowerShell 5.1 即可）。
- 共用資料夾（網路磁碟）需有讀取權限；送件到目的資料夾需有寫入權限。

## 4. 快速開始

1. 把 `index.html` 放在自己電腦或共用資料夾，用 Chrome 開啟。
2. **文字辨識命名**：
   1. 「選擇資料夾…」選掃描檔所在的資料夾（Chrome 詢問時按允許）。
   2. 填「來源資料夾的完整路徑」（在檔案總管打開該資料夾，點網址列複製）。
   3. 「開始辨識」→ 在清單逐筆檢查「最終檔名」「目的資料夾」，按 Enter 確認並跳下一筆。
      - 肯定正確的可按「一鍵確認『建議』」一次確認；按住 Shift 點勾選框可一次勾一段；按錯可「復原」。
      - 只要送件、不改名：加入檔案後改按「保留原檔名（不辨識）」，幾秒內依原檔名算出目的資料夾。
      - 規則判斷不出目的資料夾時，右側列出 3 個可能的資料夾（依規則放寬、你確認過的類似檔案、匯入清單中名稱相近的檔案），點選即確認並跳下一筆，或按 Alt＋1～3。
   4. 「產生送件（複製改名）的 PowerShell 程式碼」→ 複製 → 貼到 Windows PowerShell 執行。
3. **素材索引**：「匯入 CSV」選檔案清單（見第 10 節），即可搜尋與篩選。

辨識結果、匯入的清單與規則都會記在這台電腦的瀏覽器，下次開啟自動接續。

## 5. 三份規則

工具內建的是**通用範本**（標案代碼 A101、路徑 `\\伺服器\共用資料夾\本單位` 等），**正式使用前一定要換成單位自己的規則。**

| 規則 | 檔案 | 在哪裡改 | 主要內容 |
|---|---|---|---|
| 分類規則 | `.json` | 分類規則分頁直接編輯，或匯入／匯出規則檔 | 計畫關鍵字、標別代碼、大類／細項關鍵字、不列入的副檔名、個人資料夾例外名稱、網頁標題 |
| 命名規則 | `規則.xlsx` | **「文件類別」直接在命名規則分頁編輯**；其他工作表「下載目前規則.xlsx」→ Excel 修改 →「匯入規則.xlsx」 | 文件類別（判定關鍵字、判定正則、命名範本）、欄位擷取（正則、輸出格式）、關鍵字校正、文字替換 |
| 目的資料夾規則 | `自動歸檔規則.xlsx` | **「分送規則」直接在目的資料夾規則分頁編輯**；其他工作表「下載目前規則.xlsx」→ Excel 修改 →「匯入規則.xlsx」 | 案別、事件、次別、階段、根目錄、分送規則 |

**直接編輯**：表格可新增（＋ 新增一列）、刪除（✕）、上下移（↑↓）與修改；改完立即生效並記在這台電腦，「下載目前規則.xlsx」會下載含修改的版本，可分享給同仁或保存。紅框表示正則有誤，或範本用到不存在的欄位／變數。命名規則改完可按「套用到已辨識的檔案」，用已辨識的文字重新命名，不必重新辨識（已確認的檔案不變）。

規則檔內各工作表的「說明」頁有欄位定義。重點：

- **命名範本**：`{欄位名稱}` 會換成「欄位擷取」抓到的值，例如 `{標案}-第{期別}期估驗書` → `A101-第3期估驗書.pdf`；任一欄位抓不到就標「待確認」。
- **正則**套用在「去空白、全形轉半形」後的文字上，括號、冒號請用半形。
- **分送規則**由上而下取第一條符合者；目的地樣板可用「根目錄」工作表的變數（如 `{專區}`、`{公用表單}`）及 `{計畫}`、`{案}`、`{n}`（次別）。
- **路徑狀態**填「待確認」的規則不會產生送件程式碼；確認資料夾存在後改成「現有」。
- 「根目錄」有「試行值」與「正式值」兩欄，在目的資料夾規則分頁切換；先用試行值（本機測試資料夾）跑通，再切正式值。

## 6. 建立命名規則（逐步調整）

1. **先辨識一批**：每種常見文件挑 3～5 份，一起辨識。
2. **看「無法判定文件類別」的檔案**：展開右側「辨識文字」，找這類文件每份都會出現、別類不會出現的詞（例如「監造暨品質月報」）。
3. **新增文件類別**：命名規則分頁按「＋ 新增一列」，填類別名稱、判定關鍵字（多個詞用 `|` 分隔，須全部出現）；越專一的類別「優先序」數字越小，先判定。
4. **寫命名範本**：用表格下方列出的 `{欄位}` 組合，例如 `{標案}-第{期別}期估驗書`。需要新欄位時（例如報告年月、版次），下載規則.xlsx，在「欄位擷取」新增一列正則後匯入。
5. **處理常錯字**：4 字以上的標案全名、廠商名稱加到「關鍵字」（模糊校正）；短詞的固定錯字加到「文字替換」。
6. **按「套用到已辨識的檔案」**：不必重新辨識，直接看新檔名；不對就回到第 3～5 步。
7. **下載目前規則.xlsx** 保存並分享給同仁。

## 7. 建立目的資料夾規則（逐步調整）

1. **根目錄**：在「根目錄」工作表填試行值（本機測試資料夾）與正式值（共用資料夾），於目的資料夾規則分頁上方切換。
2. **案別**：每個標案／契約一列（代碼或代碼樣式、全名、常用簡稱、所屬計畫、施工或監造）；這張表決定能不能認出案別，最常需要補。
3. **試算**：輸入典型檔名（建議用文字辨識命名的最終檔名），看認出的案別、事件、次別與目的地。
4. **分送規則**：在表格新增或修改列，條件填事件、案類型、計畫（`*`＝不限），目的地樣板用 `{專區}`、`{計畫}`、`{案}`、`{n}` 等變數；新路徑先標「待確認」。
5. **排序**：由上而下取第一條符合者，專一的規則放上面，`*`、`（無事件）` 這類通用規則放最後。
6. **試送**：切到試行值送幾份，確認資料夾正確後把路徑狀態改為「現有」，再切回正式值。

## 8. 請 AI 幫忙建立規則

最省力的方法是用 Claude 的「DocRoute 規則產生器」技能（docroute-rule-builder）。交給它檔案清單，它會先研究，再用選擇題問你，最後交回兩個規則檔。

1. **準備**：檔案清單 CSV（可多份，格式見第 10 節），以及兩個規則檔。兩個規則檔在「命名規則」「目的資料夾規則」分頁各按一次「下載目前規則.xlsx」取得。
2. **交給 Claude**，說：「幫我用這些清單建立命名和歸檔規則」。
3. **回答選擇題**：它會先說明你們的檔案大致怎麼放，再問你這些事：
   - 要處理哪些文件
   - 哪些代碼是標案
   - 檔名怎麼寫
   - 要放哪個資料夾
4. **拿回兩個規則檔**：檔名為 `規則_日期.xlsx` 和 `自動歸檔規則_日期.xlsx`。Claude 會一併告訴你目前有多少檔案已在正確位置，以及還要你確認的地方。
5. **匯入**：在兩個規則分頁按「匯入規則.xlsx」，再用「試算」輸入幾個檔名看看。
6. **邊用邊修**：遇到判錯的檔案，把檔名和你要的結果丟回給 Claude，它會再問你、再修正。

其他情況：

- **用其他 AI，或沒有安裝技能時**：另外附上說明頁的「給 AI 的說明」，也就是本資料夾的 `AI協作說明.md`。這份是寫給 AI 看的，你不必讀。
- **清單太大、上傳不了時**：改附說明頁的「資料夾摘要」，它會把整個清單縮成一份資料夾樹，並略過個人資料夾。

AI 只需要檔名、路徑和文件首頁文字。機密與個資請先排除，並依機關生成式 AI 使用規範辦理。

## 9. 導入新單位

1. **盤點現況**：用第 10 節的方法掃描常用資料夾，產生檔案清單 CSV；指定一個「整理得最好的資料夾」當標準答案。
2. **確認習慣**：哪些文件由公文系統保存、不另存；哪些資料夾別人看不到；有沒有不能移動的資料夾。
3. **建立規則**：依第 6、7 節逐步調整，或依第 8 節請 AI 協助；分類規則填計畫關鍵字與標別代碼（三欄都留空時全部檔案都列入）。
4. **試行**：根目錄用「試行值」；選一種文件、一位同仁試用一兩週，用標準答案資料夾回測。
5. **上線**：切「正式值」；規則固定由一人維護，下載規則檔分享給同仁，避免每台電腦規則不同。

## 10. 檔案清單 CSV 格式

最簡單的方法：在網頁「說明」分頁按「下載：檔案清單掃描.bat」（本資料夾也附同一個檔案），點兩下執行，貼上要掃描的資料夾路徑（或按 Enter 開啟選擇視窗），CSV 預設存到桌面「資料夾名稱(全)_日期.csv」。只讀取檔名、路徑、大小與日期，不開啟、不修改任何檔案；無法讀取的資料夾會略過並另存清單。電腦不允許執行 .bat 時，可把副檔名改成 .ps1，按右鍵「用 PowerShell 執行」，或改用下面的指令。

**不用 CSV**：在「素材索引」按「從資料夾讀取…」，貼上資料夾的完整路徑並選擇同一個資料夾，網頁直接讀出檔案清單加入索引（網路資料夾約每秒 100 個檔案，和 .bat 差不多；只讀檔名、大小、修改日期）。之後在「已匯入」該清單旁按 ⟳，會重新讀取並先列出新增、刪除的檔案，確認後才更新；也可「另存 CSV」。用 CSV 匯入的清單同樣可以按 ⟳ 改從資料夾更新。Thumbs.db、Office 暫存檔等隱藏檔讀不到，但這些本來就不列入索引。

素材索引需要的欄位：`FileName`、`FullPath`、`RelativePath`、`Directory`、`LastWriteTime`（UTF-8，第一列為欄位名稱）。可用下列 PowerShell 產生（改第一行的資料夾）：

```powershell
$root = '\\伺服器\共用資料夾\本單位'
Get-ChildItem -LiteralPath $root -Recurse -File -ErrorAction SilentlyContinue |
  Select-Object @{n='FileName';e={$_.Name}}, @{n='FullPath';e={$_.FullName}}, @{n='Directory';e={$_.DirectoryName}},
    @{n='RelativePath';e={$_.FullName.Substring($root.Length).TrimStart('\')}},
    @{n='LastWriteTime';e={$_.LastWriteTime.ToString('yyyy/MM/dd HH:mm:ss')}} |
  Export-Csv -LiteralPath "$env:USERPROFILE\Desktop\檔案清單.csv" -NoTypeInformation -Encoding UTF8
```

可一次匯入多份 CSV，也可分次加入。匯入時會把「個人資料夾」名稱遮蔽為○○（單位資料夾下一層 2～4 個中文字的資料夾；例外名稱在分類規則「其他設定」）。

## 11. 送件：用 PowerShell 把檔案送到目的資料夾

1. 文字辨識命名：逐筆確認最終檔名與目的資料夾；素材索引：用「歸檔建議」篩選後勾選檔案。
2. 按「產生送件（複製改名）的 PowerShell 程式碼」（素材索引為下方的「送到建議位置」），選存放方式：
   - **送到各自的「目的資料夾」**（預設）：每份送到右側顯示的目的資料夾，資料夾不存在會自動建立。
   - **執行時選一個資料夾**：全部放在一起，附「檔名對照表」；選桌面時會自動建「改名複本_日期時間」資料夾。
3. 按「複製程式碼」→ 開始選單搜尋並開啟「Windows PowerShell」→ `Ctrl`＋`V`（或滑鼠右鍵）貼上 → `Enter`。
4. 畫面逐筆顯示「檔名 → 目的資料夾　結果」，最後列出新建立的資料夾；送達紀錄存在「文件\文字辨識命名工具\送達紀錄_日期時間.csv」。
5. 原檔：預設保留（只複製）；也可選「送達並核對無誤後刪除原檔」，程式核對大小與內容（SHA256）一致才刪除。共用資料夾上的檔案刪除後不進資源回收筒。目的資料夾已有同名檔時略過、不覆蓋。
6. **退回**：送錯時按第 4 步的「退回上次送件…」，把程式碼貼到 PowerShell 執行，選要退回的那一次（直接按 Enter＝最近一次），輸入 Y 確認。
	- 原檔已刪除的：把送達的檔案搬回原位置、改回原檔名。
	- 原檔還在的：核對內容相同後移除送達的複本。
	- 送件時新建、退回後變空的資料夾一併移除；送達後被改過的檔案不會動。
	- 退回依據的是這台電腦「文件\文字辨識命名工具」裡的送達紀錄。

不會送的檔案：沒有目的資料夾（規則判為「不歸檔」「人工」）、目的地路徑「待確認」、來源路徑含個人資料夾（○○）。可在右側手動填目的資料夾，或確認路徑後改為「現有」。

## 12. 辨識說明與限制

- 每份讀前 3 頁；有文字層（電子檔轉 PDF）直接取文字，沒有才辨識。判定不出類別或缺欄位時，自動改用彩色影像、忽略文字層再讀一次。
- 掃描頁約 2～6 秒／頁（依電腦而定），可設定同時處理 1～8 份；一次建議數十份以內。
- 公文、簽、開會通知單一律標「待確認」，因慣用檔名常與來文主旨不同。
- 常見的短詞辨識錯誤可在命名規則「文字替換」補正（內建「請查照」「請鑒核」兩條）。
- 檔名開頭有 7 碼民國日期但判斷不出事件的檔案，範本規則會判為「不歸檔」（一般往來公文由公文系統保存），可在分送規則調整。

## 13. 隱私

- 檔案只在使用者電腦的瀏覽器中讀取與辨識，不上傳任何地方；網頁不連網路。
- 匯入的清單、規則與辨識結果存在該電腦的瀏覽器（IndexedDB／localStorage）；換電腦或清除瀏覽器資料後需重新匯入。
- 規則檔含資料夾路徑，分享前請確認可以公開。
